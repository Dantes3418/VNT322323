Link personalizado por vendedor

Comparte este link con cada ejecutivo. El parámetro ?ejecutivo=NOMBRE filtra automáticamente para mostrar solo sus ventas. El nombre debe coincidir exactamente con el que aparece en la columna "Ejecutivo" de tu hoja.

Ejemplo: si el archivo se llama dashboard.html y está en tu escritorio o hosting:

dashboard.html?ejecutivo=AILYN
dashboard.html?ejecutivo=CARLOS
dashboard.html?ejecutivo=SOFIA

Código para Google Apps Script

En tu Google Sheet ve a Extensiones → Apps Script, borra todo y pega este código. Luego publica como Web App (Implementar → Nueva implementación → Aplicación web → Cualquier persona).

function doGet(e) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const hoja = ss.getSheetByName("Hoja1"); // ← cambia por tu hoja
  const datos = hoja.getDataRange().getValues();
  const filas = datos.slice(1);

  const resultado = filas
    .filter(f => f[0] !== "")
    .map(f => ({
      ci: f[0].toString(),
      plan: f[1].toString(),
      estado: f[2].toString().toUpperCase(),
      celular: f[3].toString(),
      ejecutivo: f[4].toString().toUpperCase(),
      cliente: f[5].toString(),
      cuenta: f[6].toString()
    }));

  return ContentService
    .createTextOutput(JSON.stringify(resultado))
    .setMimeType(ContentService.MimeType.JSON);
}
